# The Patio Bella

Website concept for The Patio Bella. Next.js 16 (App Router, Cache Components),
React 19, TypeScript, Tailwind CSS 4, GSAP 3.15.

```bash
npm install
npm run dev        # http://localhost:3000, motion test bench at /motion-lab
npm run typecheck  # next typegen + tsc
npm run lint
npm run build
```

Animation conventions: [docs/MOTION.md](docs/MOTION.md).
